# إعداد وتشغيل البوت

## المتطلبات

ثبّت الاعتماديات من مجلد `bot`:

```bash
pip install -r requirements.txt
```

## إعداد المفاتيح

لا توجد أي أسرار داخل الكود. انسخ `.env.example` إلى `.env` واملأ القيم (أو عيّنها كمتغيرات بيئة على الخادم):

```bash
cp .env.example .env
```

- `BOT_TOKEN` و`ADMIN_ID`: مطلوبان، والبوت لا يعمل بدونهما.
- `TONAPI_KEY`: عند استخدام ميزاته فقط.
- `EGP_RATE_MODE`: `p2p` افتراضيًا، أو `official` للسعر الرسمي، ويمكن تثبيت سعر يدوي عبر `EGP_USD_OVERRIDE`.

سعر TON هو وسيط (median) لحظي من Binance وOKX وBybit وKraken وCoinbase؛ أي مصدر يبعد أكثر من 1% عن الوسيط يُستبعد، ويلزم مصدران متفقان على الأقل، وCoinGecko احتياطي فقط. سعر الجنيه من Binance P2P، ولو تعذّر يعرض البوت السعر الرسمي مع تنبيه.

## التشغيل

```bash
python bot.py
```

## بعد انتهاء الاشتراك أو التجربة

تظل لوحة التحكم في الخاص ظاهرة ومتاحة، بما فيها زر «ربط الحساب» والإعدادات. تتوقف معالجة رسائل محادثات Business والردود الآلية للعملاء حتى تفعيل الاشتراك من جديد.

## فحص قنوات البلاغات

إدارة قنوات البلاغات والفحص اليدوي الإداري تبقى للمدير فقط. أما المستخدمون فيستطيعون طلب البحث العام في الخاص بالطرق الموضحة أدناه. مركز الأمان وفحص الروابط القديم أُزيلا.

## فحص النصابين من الخاص

لا يبدأ الفحص إلا عند إرسال `فحص كاش`، ويمكن إضافة `@username` أو ID في نفس الرسالة، أو إرسال «فحص كاش» وحدها ثم إدخال اليوزر أو الـ ID في الرسالة التالية. كلمة `كاش` وحدها لا تشغّل الفحص. الفحص يعمل على منشورات القنوات العامة التي يضيفها المدير فقط. نتائج البحث قرائن من المنشورات العامة وليست حكمًا قاطعًا، ولا تشمل القنوات الخاصة أو كامل الأرشيف.
